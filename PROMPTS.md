J'ai utilisé l'IA comme un formateur : pour comprendre, être guidée et relue. L'IA ne donne pas de réponse ni de code sans mon accord. Quand du code vient de l'IA, il est expliqué puis testé. Chaque suggestion rejetée est notée avec sa raison.
